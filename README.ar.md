# مرصد سعر الدولار في العراق — سلسلة يومية لسعر الصرف في السوق الموازية

العربية | **[English](README.md)**

توفير قاعدة بيانات مفتوحة لجمع ومتابعة سعر صرف الدولار الأمريكي في **السوق الموازية**
في العراق، اعتمادا على قناة @dollariraqi العامة. ينتج المشروع سلسلة يومية تشمل
سعري الافتتاح والإغلاق للمحافظات الرئيسية في العراق — وهو السعر الذي لم يعد البنك
المركزي العراقي ينشره.

- **اللوحة المباشرة:** `https://HusseinKh90.github.io/Iraq-parallel-exchange-rate/`
- **البيانات:** [`data/daily_fx.csv`](data/daily_fx.csv) — متاحة للتنزيل والاستخدام بحرية
- **المنهجية:** طريقة جمع السعر وتنظيفه واحتساب معدلاته موضحة في الأسفل

> **ليس سعرا رسميا وليس نصيحة مالية.** هذه بيانات مجمعة من السوق الموازية مصدرها
> قناة عامة، وليست سعرا صادرا عن البنك المركزي.

## طريقة الاستخدام

```bash
pip install -r requirements.txt
python iraq_fx_parser.py run
```

> في ويندوز استخدم الأمر `python` (أو `py`)، وفي ماك ولينكس غالبا `python3`.

لا يحتاج البرنامج إلى أي ملف إدخال يدوي. يعمل على مرحلتين، والأمر `run` ينفذهما
معا، وذلك من خلال جمع المنشورات من القناة إذا لم تكن محفوظة من قبل، ثم تحليل
وتجميع البيانات.

```bash
python iraq_fx_parser.py scrape   # جمع المنشورات من القناة   -> data/raw_posts.jsonl
python iraq_fx_parser.py parse    # تحليل المنشورات المحفوظة  -> data/daily_fx.csv
python iraq_fx_parser.py run      # يجمع (عند الحاجة) ثم يحلل   [الوضع الافتراضي]
```

تقوم مرحلة الجمع (`scrape`) بتنزيل الصفحة العامة للقناة
(`https://t.me/s/dollariraqi`) مباشرة، من دون تسجيل دخول أو API، وتحفظ
المنشورات كما هي في الملف `data/raw_posts.jsonl`. أما مرحلة التحليل (`parse`)
فتقرأ هذا الملف وتتولى التنظيف والتصنيف واستخراج الأسعار. الفصل بين المرحلتين يعني
أنك تجمع البيانات مرة واحدة، ثم تعيد تحليلها بسرعة متى شئت.

## المخرجات

- `data/raw_posts.jsonl` — المنشورات الخام كما تم جمعها (الملف الذي يقرأه المحلل).
- `data/daily_fx.csv` — صف واحد لكل يوم عمل، مع سعري الافتتاح والإغلاق لكل مدينة.
- `data/unmatched_posts.jsonl` — منشورات تحتوي على أسعار لكن لم يتم ربطها بمدينة
  معروفة، محفوظة للمراجعة.

## بيانات تجريبية

يحتوي مجلد `data/` على عينة صغيرة من ملف `raw_posts.jsonl` (بعض المنشورات
الحديثة) وملف `daily_fx.csv` الناتج عنها، حتى يعمل المشروع ويمكن فحصه من دون
الحاجة إلى الاتصال بتيليغرام. استخدم الأمر `scrape` (أو `run --refresh`)
لاستبدال العينة بالسجل الكامل.

## السلاسل الزمنية لسعر الصرف

`baghdad_generic`، `baghdad_kifah`، `baghdad_harithiya`، `baghdad_retail`،
`erbil`، `erbil_retail`، `sulaymaniyah`، `karbala`، `najaf`، `basra`،
`kirkuk`، `mosul`

الأعمدة: `{city}_open` و`{city}_close` لكل مدينة، إضافة إلى `baghdad_avg_open`
و`baghdad_avg_close` و`daily_avg_open` و`daily_avg_close` و`n_cities_in_avg`.

ملاحظة: سلسلتا التجزئة (`baghdad_retail` و`erbil_retail`)، أي أسعار الصيرفات،
تظهران كعمودين مستقلين لكنهما مستثنيان من احتساب المعدلات.

## البيانات والترخيص والإسناد

- **الوحدة:** الأسعار بالدينار مقابل دولار واحد (مثال: `1507.8`). تكتب الأسعار في
  العراق عادة بالدينار مقابل 100 دولار (مثال: `150,780`)، فاضرب في 100 للحصول على
  الصيغة المتداولة في السوق.
- **المصدر:** قناة تيليغرام العامة [@dollariraqi](https://t.me/dollariraqi). هذا
  المشروع تجميع مستقل مشتق منها وغير تابع لها.

- **تنبيه:** هذه ملاحظات من السوق الموازية، وليست سعرا رسميا للبنك المركزي
  العراقي، وليست نصيحة مالية.
